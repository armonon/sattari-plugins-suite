The visual source of truth. Every component here uses tokens.css. Port these to JUCE by matching the exact spacing, radii, type sizes, and colors — all of which are tokens, not ad-hoc values. The goal is that a built component is indistinguishable from its reference here. Restraint is the point: few values, generous space, one accent doing meaningful work, nothing louder than it deserves.

1 · Stem gain knob (0 / 100 / 200, center-unity)

The signature control. 12 o'clock = 100 (unity). Left → 0 (silence). Right → 200 (×2 boost). Arc fills from 12 o'clock: stem color when boosting, amber above ~175 approaching clip. Below unity the arc is neutral. Double-click resets to 100. Drag vertical (ns-resize). Maps to a linear gain multiplier: 100=×1.0, 200=×2.0. Interact with the live ones below.

2 · Vertical stem column (the waveform detail unit)

Four of these side by side make the detail view. Scrolls down, bar numbers in the gutter, a horizontal "now" line. Column is labelled always (unlabelled color = guessing game). Knob docks directly beneath — the vocal knob under the vocal wave. A muted column dims to ~40%. Each column has a small ƒx slot top-right that opens the FX panel scoped to that stem.

3 · Segmented deck panel (replaces five stacked rows)

The density fix. A segmented control (CUES/LOOP/FX/SRC) swaps one panel below it — iOS-tab pattern. Click a segment above to swap the panel. Core transport (play, cue) stays always-visible above; only the lower panel swaps. In the real build the swap is a 160ms crossfade/slide, interruptible — that transition is where the "Apple-clean" feel lives.

4 · Channel states — active vs idle (weight matches content)

The rule that keeps 6+ channels readable. An active channel shows its full body. An idle channel (empty deck, no-instrument MIDI, no-signal input) collapses to a slim strip and recedes — it must never be louder than a loaded channel. Idle→active is an animated expansion, not a pop.

7 · Dual-tempo panel

Both tempos at once (replaces djay's toggle). Track BPM shows confidence and flags likely octave errors (djay has no confidence signal). Live tempo carries key+formant lock. The purple retroactive lane — perform at 124, ride to 128, re-times on export — is the feature djay can't build.

How to use this: open in a browser next to your build. Match spacing, radii, type sizes, and color to the token names — not to eyeballed values. When a built component looks different from its reference here, the reference wins. Restraint over addition: if it looks busy, remove and enlarge, never add.
