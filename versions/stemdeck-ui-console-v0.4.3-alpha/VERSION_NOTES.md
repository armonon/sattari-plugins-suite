# StemDeck UI Console Snapshot

Snapshot date: 2026-07-10

This folder preserves the StemDeck v0.4.3 Alpha console-style UI pass as a standalone reference copy.

## Included

- `stemdeck/` - source snapshot copied from `plugins/stemdeck`
- `STEMDECK_SHARE_README.md` - shareable overview/readme for the alpha

## What This Version Captures

- Four-deck DJ/remix workspace layout
- Dark hardware-console visual treatment
- Deck-colored controls for A/B/C/D
- Custom StemDeck button, toggle, fader, knob, and combo box rendering
- Right-side FX, record, and event-log rail
- Compact workflow guidance: load, split, mix, record

## Notes

This snapshot is outside the live `plugins/` tree on purpose so it can be kept as a reference without changing plugin discovery or CI build behavior.
