Cross-Plugin Key Bus

Set the key once. Every plugin follows.

The Sattari cross-plugin session bus is a lock-free shared memory channel that runs across every plugin instance in your session. Sattari Key publishes the detected key every 700 ms — all key-aware plugins subscribe and update immediately.

No MIDI routing. No parameter automation. No manual key entry across 10 plugins.

  • 24-key Krumhansl–Schmuckler detection — major and minor
  • Manual override on any plugin without affecting others
  • Works across AU and VST3 in the same session
  • Zero latency: lock-free atomic reads on the audio thread
