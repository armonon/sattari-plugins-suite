# Phases 2-5: harmonic intelligence, Follow Song Map, intent, harmony

## What was built

**Phase 2 — harmonic intelligence.** `ChordAnalyzer` (9 templates: triads,
dim/aug, sus2/4, maj7/min7/dom7) where complexity must be EARNED — sevenths
carry a handicap so a plain triad is never promoted — plus a mild diatonic prior
a borrowed chord can still overcome. Modulations classify as key change / modal
shift / relative shift / possible tonicization, computed from SCALE REGIONS that
already survived smoothing and short-region absorption, so one chromatic chord
can never move the map.

**Phase 3 — Follow Song Map + intent engine.** Analysed scale regions feed the
same validated follower table the Key Map scan uses. Correction is scaled by an
intent confidence built from four independent doubts.

**Phase 4 — harmony planning.** `HarmonyVoicePlanner` with real voice leading:
candidates scored on closeness to the voice's previous note, register, and
collision/crossing avoidance.

**Phase 5 — EDIT** got the full-height surgical layout in the earlier
workspace commit.

## The measurement that shaped Phase 2

Per-frame chord margins on REAL audio measure **p50 0.012, max 0.06** across
GiantSteps tracks — an order of magnitude below synthetic templates, because
real chords share most of their notes. Thresholding that raw number passes
everything or nothing.

So region confidence became **agreement**: 5-frame majority vote, then the
fraction of original frames that independently chose the region's chord. That is
calibrated 0..1, comparable with every other confidence in the suite, and it is
the same discipline that took the Key Map from 167 flicker segments to 1.

## The adversarial review found 29 real defects, 6 of them blockers

A four-lens review (threading / correctness / UI / honesty) with
refutation-first verification. The suite was fully green throughout.

**The worst was mine and it was the exact defect class this project has already
fixed once.** `keyMapDriving()` was widened to accept Follow Song Map, but the
single call site performing the lookup stayed gated on the OLD parameter — so
**Follow Song Map was a dead automatable control**, precisely like
`liveEngine`/`lowLatency`. Worse, the widened predicate latched on a stale
segment index nothing could reset, freezing the correction key for the session
and silently suppressing AutoKey.

Fixed, plus:

| 2 | stale segment latch froze the key forever | early return clears the latch |
| 3 | `clearSongFileResult` left the old follow table live | clears it and the latch |
| 4 | intent gate throttled MIDI Target / Pitch Edits to 20% | deliberate targets bypass the gate |

| 6 | key trust penalised manual/bus/song-map keys | keys off the ACTUAL origin |
| 7 | 21 dead harmony parameters | level/pan REMOVED; degrees/octave added and used |
| 8 | Interval mode planned one note for all voices | per-voice degrees |

## Verification

`AutoPitchRender --followmap` exists **because the dead-control defect was
invisible to every other test.** It analyses a song, then drives the follower at
each region and asserts the effective correction root:

```
   0.0- 30.2  E major  conf 0.134     at  15.1s -> SONG MAP root=E
  30.2- 60.4  B major  conf 0.033     at  45.3s -> not-map  (below gate)
  60.4-120.0  E major  conf 0.072     at  90.2s -> not-map  (below gate)
```

The confident region drives correction to its own key; sub-gate regions do not
drive at all.

## What is NOT done

- **Harmony plans notes; it does not render voices.** Four independently shifted
  streams is substantial DSP that does not exist. The workspace states
  "VOICE RENDERING NOT YET CONNECTED" in every state, and the level/pan
  parameters were REMOVED rather than shipped dead.
- **Sections stay neutral A/B/C.** Naming a Chorus needs repetition analysis.
- **Extended chords beyond sevenths** are not attempted.
- **No listening evidence, no host testing**, CI still billing-blocked.
- Chord/modulation accuracy has **no ground-truth corpus** — the contract proves
  behaviour, not accuracy. A labelled chord set is the honest next step.
