# Listening evidence

Human listening results only. Claude may prepare renders, A/B and ABX files,
randomized labels, listening forms, parameter snapshots and metric summaries —
Claude may **not** fabricate the judgments.

If a report does not exist here for a claim, the correct statement is:

    LISTENING STATUS: NOT VERIFIED

Start from `validation/templates/listening-test-report.md`.

Naming: `YYYY-MM-DD-<product>-<what-was-tested>.md`

Building a blind package for a candidate: `2026-09-25-listening-package-howto.md`
(`scripts/make_candidate_kit.sh` here, `build_listening_package.py` on the machine with the vocals).
